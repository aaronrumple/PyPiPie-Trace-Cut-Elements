# Trace Cut Elements

A pyRevit tool for generating consolidated **Filled Regions** or **Masking Regions** from model elements cut by the active Revit view.

> **Acknowledgment**  
> This tool is based on and substantially extends the concepts/code from **mjcobb/PyRevit-Hatching-Extension**:  
> https://github.com/mjcobb/PyRevit-Hatching-Extension
>
> The original extension provides the core *Unite Section* workflow for merging geometry cut by section/elevation/detail views into a filled region. Trace Cut Elements expands that workflow with plan/RCP support, crop clipping, masking regions, configurable line styles, diagnostics, and progress/cancel handling.

## Features

- Supports **Sections**, **Elevations**, **Detail Views**, **Floor Plans**, and **Reflected Ceiling Plans**.
- Creates either a **Filled Region** or **Masking Region**.
- Combines touching cut geometry where possible into consolidated region outlines.
- Preserves openings/holes where Revit accepts the resulting loops.
- Clips generated geometry to the active view's **crop box** when the crop is active.
- Uses the **View Range Cut Plane** for Floor Plans and RCPs.
- Allows selection of model categories to include.
- Remembers category selections between runs.
- Configurable Filled Region type.
- Configurable region boundary/detail-line style.
- Replaces regions previously generated by the tool in the same view.
- Draws rejected outlines as temporary grouped detail lines for troubleshooting.
- Includes progress bars with cancellation for geometry processing and solid merging.
- Reports geometry, Boolean, crop, and outline failures when Revit cannot create a region.

## How It Works

The command uses a slice-first approach:

1. Collect candidate model elements visible in the active view.
2. Ask which available categories should participate.
3. Extract solid geometry from those elements.
4. Reduce the solids to a thin slice at the view cut plane.
5. Clip the slice to the active crop box when applicable.
6. Boolean-union touching pieces where possible.
7. Extract planar outlines at the cut plane.
8. Clean short segments, duplicate points, spikes, and problematic loops.
9. Create the selected Filled Region or Masking Region.
10. Tag generated regions in **Comments** so the next run can replace them.

Pieces that cannot be unioned are retried at alternate slice depths and, when necessary, processed separately.

## Plan and RCP Support

Floor Plans and Reflected Ceiling Plans use the Revit **View Range Cut Plane**, rather than `View.Origin.Z`.

The absolute cut elevation is calculated from:

```text
Cut Plane Level ProjectElevation + Cut Plane Offset
```

For plan/RCP geometry, the command constructs an explicit horizontal slab immediately below the Cut Plane and intersects element solids with that slab. This avoids ambiguity associated with half-space Boolean orientation.

The default slice depth is:

```python
SLAB = 0.25  # feet (3 inches)
```

## Crop Region

When the active view has an enabled crop box, the generated poche geometry is physically clipped to the crop boundary before region creation.

When the crop is inactive, no crop clipping is applied.

## Configuration

Use **Shift+Click** on the pyRevit button to open the configuration dialog.

The dialog allows configuration of:

- **Output Kind**
  - Filled Region
  - Masking Region
- **Filled Region Type**
- **Region / diagnostic line style**

Settings are stored using the pyRevit command configuration system and reused on subsequent runs.

## Category Selection

Each normal run displays the categories currently represented by candidate elements in the active view. Categories can be checked or unchecked before processing.

Typical supported categories include:

- Walls
- Floors
- Roofs
- Windows
- Doors
- Structural Columns
- Structural Framing
- Structural Foundations
- Ceilings
- Stairs
- Columns
- Railings
- Curtain Panels and Mullions
- Casework
- Furniture
- Specialty Equipment
- Generic Models
- Toposolids

The previous category selection is remembered.

## Progress and Cancellation

Progress is displayed during the more expensive operations, including:

- Reading and slicing element geometry
- Merging solid pieces

The progress dialogs are cancellable so large or problematic views can be stopped without waiting for the complete operation.

## Re-running the Command

Generated regions are tagged in the **Comments** parameter with:

```text
Trace Cut Elements
```

Before creating new regions, the command removes previously generated Trace Cut Elements regions from the active view. This allows the command to be rerun after model changes without manually deleting the previous result.

## Rejected Geometry

Revit can reject region loops because of conditions such as:

- Very short segments
- Self-intersections
- Zero-width spikes
- Touching openings
- Boolean failures
- Invalid region-loop topology

The command attempts several cleanup and recovery operations. When an outline still cannot be converted into a region, it can be drawn as grouped detail lines using the configured line style so the geometry can be inspected directly in Revit.

These diagnostic elements are also replaced on the next run.

## Diagnostics

When no valid cut geometry is found in a Plan/RCP, the command reports information such as:

```text
Elements checked
Solids found
Outside View Range slice
Slice Boolean errors
Outside crop
Crop Boolean errors
Cut Plane level
Level ProjectElevation
Cut Plane offset
Calculated Cut Z
Slice bottom Z
Solid geometry Z range
```

This is intended to make View Range, coordinate-system, and geometry problems easier to diagnose.

## Requirements

- Autodesk Revit
- pyRevit
- Revit API access through pyRevit

The current implementation is written for the IronPython-compatible pyRevit environment.

Masking Region creation requires a Revit API version that exposes `FilledRegion.CreateMaskingRegion`.

## Installation

Place the command files in the appropriate pyRevit pushbutton bundle, for example:

```text
PyPiPie.extension/
└── PyPiPie.tab/
    └── Annotation.panel/
        └── Filled Regions.pulldown/
            └── Trace Cut Elements.pushbutton/
                ├── Trace Cut Elements_script.py
                └── Trace Cut Elements_config.py
```

Reload pyRevit after copying or updating the files.

## Known Limitations

- Revit Boolean operations can fail on unusually complex or malformed geometry.
- Some openings that touch an exterior boundary may need to be slightly adjusted or omitted for Revit to accept the region.
- Elements without usable solid geometry cannot contribute to the result.
- Region creation is subject to Revit's minimum curve length and loop-validity requirements.
- Plan/RCP results depend on a valid View Range Cut Plane.
- The crop-box implementation uses the view crop rectangle; non-rectangular crop-region handling may require additional processing.
