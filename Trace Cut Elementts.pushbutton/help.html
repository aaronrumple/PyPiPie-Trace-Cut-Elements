Trace Cut Elements

pyRevit tool for generating filled or masking regions from model geometry cut by the active view.

Purpose

Trace Cut Elements creates 2D regions representing model elements cut by the active view. It supports sections, elevations, detail views, floor plans, and reflected ceiling plans.

The command collects selected model categories, extracts their solid geometry, reduces it to a thin slice at the cut plane, merges the resulting solids where possible, and converts the cut faces to Revit regions.

Plan/RCP processing resolves the Cut Plane level and offset and uses the level's project elevation to calculate the model-space cut elevation.

Running the Command

  1. Open a supported Revit view.
  2. Run Trace Cut Elements.
  3. Select the model categories to include. The list only contains categories available to the command, and the previous selection is remembered.
  4. Click Fill.
  5. The progress bars report geometry reading and solid merging. Click Cancel to stop processing.
  6. The generated regions are placed in the active view.
Crop regions: when the view crop is active, the generated geometry is physically clipped to the crop rectangle before the region is created.

Plan and RCP Processing

For plan-based views, the command does not rely on View.Origin.Z. It reads the View Range Cut Plane level and offset and calculates:

Cut Z = Cut Plane Level ProjectElevation + Cut Plane Offset

An explicit horizontal slab is created immediately below the Cut Plane. The default slab depth is 0.25 ft (3 inches). Each model solid is Boolean-intersected with this slab. This avoids ambiguity associated with half-space orientation in plan views.

Solid bounding boxes are transformed into model coordinates before the temporary slicing slab is constructed, allowing transformed family/instance geometry to be processed correctly.

Sections, Elevations, and Details

For non-plan views, candidate elements are first filtered by whether their bounding boxes cross the view cut plane. Their geometry is then trimmed to the thin cut-plane slab. This reduces the amount of geometry involved in the later Boolean union operations.

Categories

The command can process the following categories when present in the active view:

Walls, Floors, Roofs, Windows, Doors, Structural Columns, Structural Framing, Structural Foundations, Ceilings, Stairs, Columns, Railings, Curtain Wall Panels, Curtain Wall Mullions, Casework, Furniture, Specialty Equipment, Generic Models, and Toposolids.

The primary architectural/structural categories are selected by default on first use. Your category choices are remembered on later runs.

Geometry and Region Creation

  1. Read solid geometry at the active view detail level.
  2. Trim/intersect solids to the cut-plane slice.
  3. Clip the slice to the active crop box, when applicable.
  4. Union compatible pieces into a common solid.
  5. Retry failed unions using alternate slice depths.
  6. Keep pieces that still cannot merge as separate solids.
  7. Extract planar faces located on the cut plane.
  8. Clean short segments, straight intermediate vertices, and zero-width spikes.
  9. Classify outer loops and openings.
  10. Create the selected Filled or Masking Region.

Openings that touch an outer boundary may be shrunk by a very small amount so Revit can accept the loop. If an opening still cannot be retained, the command can fill over that opening and report it.

Replacement Behavior

Generated regions are tagged in the Comments parameter with Trace Cut Elements. On the next run in the same view, regions carrying that tag are deleted before the replacement regions are created.

Important: do not manually assign the tool's exact Comments tag to unrelated regions if you want them preserved on subsequent runs.

Rejected Outlines

If Revit refuses an outline, the command attempts several recovery methods. Outlines that remain invalid can be drawn as detail lines and grouped for inspection. These diagnostic lines use the configured line style when that style exists.

The diagnostic group is replaced on the next run so rejected geometry does not accumulate indefinitely.

Progress and Cancellation

A cancellable progress bar is displayed while reading and slicing element geometry and again while merging solid pieces. Cancellation stops the command instead of continuing through the remaining model geometry.

Large or geometrically complex views can take longer because Boolean operations are performed on actual Revit solids.

Diagnostics

If no usable cut geometry is found, the plan/RCP diagnostic can report:

  • elements checked and solids found;
  • solids outside the View Range slice;
  • slice Boolean errors;
  • crop rejection/errors;
  • Cut Plane level;
  • level ProjectElevation;
  • Cut Plane offset;
  • calculated Cut Z and slice bottom Z;
  • the Z range of the solid geometry encountered;
  • the first geometry error, when available.

These values are intended to distinguish a View Range problem from a geometry, crop, or Boolean-operation problem.

Results and Limitations

  • Boolean operations can fail on unusually complex, malformed, or nearly coincident solids.
  • Pieces that cannot be unioned may be generated as separate overlapping regions.
  • Very small curves are removed because Revit will reject boundaries below its short-curve tolerance.
  • The command works from Revit model solid geometry; the available categories are defined by the script.
  • The current script has SKIP_GLASS = False, so glazing is not automatically excluded.
  • The cut slice depth is currently SLAB = 0.25 ft.
